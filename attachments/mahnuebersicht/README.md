# Mahnübersicht (Mock)

Der aktuelle Stand der Mahnübersicht, herausgelöst aus dem Produkt. Es gibt kein Backend, alle Daten kommen aus `src/data/posten.ts`.

```bash
npm install
npm run dev
```

Danach läuft der Mock unter <http://localhost:5180>.

| Ort | Inhalt |
| --- | --- |
| `src/data/posten.ts` | Datenmodell und Beispieldaten |
| `src/components/` | Kennzahlen, Tabelle, Mahnstufen-Kennzeichnung |
| `src/App.tsx` | Die Seite selbst inklusive Mahnlauf |
